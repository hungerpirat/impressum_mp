# Impressum – Kiosk Wilking

Schlichte, mobilfreundliche HTML-Seite ohne externe Abhängigkeiten, Schriftarten oder Tracking. Telefon und E-Mail sind direkt verlinkt.

## Auf GitHub Pages veröffentlichen

1. Die Datei `index.html` in das GitHub-Repository hochladen.
2. Im Repository unter **Settings → Pages** als Quelle **Deploy from a branch** auswählen.
3. Den Branch mit der Datei (z. B. `main`) und den Ordner **/ (root)** auswählen und speichern.
4. Nach der Veröffentlichung die unter **Settings → Pages** angezeigte URL als Impressumslink im Instagram-Profil hinterlegen.

Zum lokalen Ansehen `index.html` im Browser öffnen.
